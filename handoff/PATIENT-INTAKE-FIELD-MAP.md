# Patient intake field map

The protected registration flow is based on the clinic-provided Adult Patient Chart demographics and financial-information page.

## Collected in protected registration
- email / mobile phone
- account password
- legal first and last name
- preferred name
- date of birth
- preferred language
- existing medical record ID, when already assigned
- home address / city / state / ZIP
- pronouns / preferred form of address
- interpreter need
- emergency contact name / relationship / phone
- referring or primary physician, if any
- optional insurance company, member/policy ID, group number, subscriber name/relationship/date of birth
- optional ethnicity, gender identity, sex assigned at birth, veteran status

## Intentionally not collected online in this release
- Social Security number
- driver's-license number
- medical-record uploads
- diagnoses, symptoms, medications, lab results, or free-text clinical history
- binding signatures for financial policy, treatment consent, arbitration, or record release

Those exclusions reduce unnecessary sensitive-data collection and avoid turning legal/clinical paper documents into unreviewed electronic-signature workflows.
