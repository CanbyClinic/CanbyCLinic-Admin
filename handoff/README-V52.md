# Canby Clinic V52 — Terminal-Matched Sprinter Hero

This build replaces the old medical-canvas hero with a 180-frame scroll-controlled cinematic rendered from the uploaded Mercedes-Benz Sprinter model.

Sequence structure:
1. Clean warm dusk side-profile vehicle hero.
2. Extended lateral tracking with visible Canby Community Clinic livery.
3. Industrial terminal/loading-dock approach.
4. Cyan technical/wireframe transformation of the same vehicle geometry.
5. Elevated yard/loading-bay view.
6. Real vehicle return and bright-white handoff into the existing Canby site.

Desktop: 1600×900 WebP sequence, 180 frames.
Mobile: 720×1280 separately framed WebP sequence, 180 frames.

The frame renderer source and exact GLB used are retained under `assets/ambulance/source/`.
