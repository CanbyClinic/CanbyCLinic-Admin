# PREMIUM V7 — Locked Site / Scroll Animation

The website outside the homepage hero is locked.

## Hero behavior
- True scroll-scrub: no autoplay timer.
- Forward scroll types text letter by letter.
- Reverse scroll removes letters in reverse.
- Green highlight sits behind the currently typed text and a luminous green cursor follows the active character position.
- Three stages: CANBY → CANBY COMMUNITY CLINIC → PRIMARY CARE IN RESEDA.
- Address / phone / hours resolve at the final stage.
- 4K 3840×2160 hero background asset.
- Subtle background tracking and light sweep only; no random effects.
- Header returns to the normal site state once the hero has passed.
- English, Spanish, and Armenian homepages use the same motion system.
- Reduced-motion users receive the final message immediately.
