# Canby Clinic V53 — Type I Ambulance Terminal Hero

This build replaces the Sprinter sequence with the customized Canby/Pura Vida Type I ambulance.

- 130 scroll-controlled frames over a 200vh hero (one viewport of scroll travel)
- 1600×900 desktop sequence
- 720×1280 independently framed mobile sequence
- Real wheel rotation, suspension movement, shadows, terminal approach, controlled stop, and white handoff
- 4K-textured animation-ready GLB retained in `assets/ambulance/source/`
- Progressive frame loading with directional prefetch and bounded memory cache

The original site content, patient pages, languages, forms, and navigation are retained.
