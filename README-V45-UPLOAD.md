# Upload Instructions — Canby Clinic V45

Upload the contents of `CanbyCLinic-main/` to the root of the GitHub repository.

The repo root should contain:

```
index.html
services.html
patient-portal.html
assets/
sitemap.xml
```

Do not upload a nested folder unless GitHub Pages is configured to publish from inside that folder.

After uploading, clear browser cache or open the site in a private window to avoid seeing the old CSS.
